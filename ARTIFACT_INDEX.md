# Final deliverables

## Paper

- `paper/Hamiltonian_Control_Study.pdf`: English academic research manuscript with mathematical statements, proofs, tables, figures, limitations and references.
- `paper/manuscript.md`: editable authoring source.
- `paper/math_appendix.md`: extended derivations of structure, bias/variance, tracking, design, MPC, SAC and sampled control.
- `paper/figures/`: actual animation storyboards and extraction provenance.
- `paper/manuscript.tex`: standalone LaTeX source generated by Pandoc.
- `paper/references.bib`: reusable bibliography.
- `paper/rebuild.sh`: manuscript rebuild command.
- `docs/CONTRIBUTIONS.md`: exact supported originality and evidence boundaries.

## Scientific evidence

- `phase1` through `phase8`: stage reports, raw numerical records and verified scientific figures.
- `phase6/phase6_report.md`: validation-selected coverage and coordinate benchmark; actual SAC, feedback and MPC results.
- `phase7/phase7_report.md`: fixed-budget acquisition, failed predeclared gate and complete query audit.
- `phase8/phase8_report.md`: independent Duffing, privileged symmetry recentering and action-hold refinement.

- `*_protocol.json`: frozen primary and explicitly labelled diagnostic protocols.

## Run

Install `requirements.txt`; install `requirements-rl.txt` for SAC. All scripts are run from the repository root. `python run_phase8.py` produces the final bounded diagnostic; `python verify_phase8.py` checks it independently. See `docs/REPRODUCIBILITY.md` for complete reproduction and archived-output inspection.

## GitHub binary layout

`artifacts/` contains every original binary dataset/checkpoint in lossless stage bundles. `restore_artifacts.py` restores canonical paths and verifies hashes. Code, text evidence, paper, figures and GIFs remain directly browsable.
