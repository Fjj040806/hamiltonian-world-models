# Complete datasets and fitted checkpoints

All original binary research files are preserved without loss in the stage bundles. GitHub displays source, raw text records, paper and visual assets directly; the bundles keep thousands of small checkpoints manageable.

From the repository root run:

```bash
python restore_artifacts.py
```

The standard-library-only script verifies bundle hashes, restores the original phase directories and verifies every extracted file. These are local files already present in the cloned repository; no extra download or authentication is needed. All original records, including unsuccessful pilots, remain included.
